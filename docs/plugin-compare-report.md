# 外部插件分析与本项目改进评估报告

> 日期:2026-08-18 ｜ 对象:Reaction_Diffusion_Generator_Pro v6(用户附件)
> 目的:分析其"预处理后纹理接近期望效果"的原因,评估可借鉴点并落地改进

---

## 1. 外部插件分析

### 1.1 核心管线(与我们的差异)

| 维度 | 外部插件 | 本项目(改进前) |
|---|---|---|
| 求解域 | **顶点域**(边图拉普拉斯 `lap=Σ邻居−degree·U`) | 面域(MeshRD,邻接表 gather) |
| 预处理 | **自动 Voxel Remesh**(按包围盒面积算 voxel_size,直接 apply) | 手动质量检查 + 引导 Remesh |
| 初始条件 | **稀疏均匀种子**(n/20 个顶点 V=1) | 中央方块/圆盘全扰动 |
| 边界 | **开放面边界 Dirichlet 保持**(U=1/V=0 固定,防边缘失真) | 无边界处理 |
| 位移 | **直接写顶点坐标**(沿顶点法线,UNDO 支持) | 属性/GN 间接置换 |
| 裁剪 | 每步 clip[0,1] ✓ | 已加 ✓ |
| 加速 | Numba JIT(pip 镜像安装) | numpy(优化内核 2x) |
| 预设 | 7 组风格化 (f,k) | 5 组 Pearson |

### 1.2 "纹理接近期望"的四个原因

1. **顶点分布均匀**(自动 Remesh 强制)——反应扩散尺度与网格密度成正比,均匀网格才有均匀花纹;
2. **顶点域直接位移**——状态就在位移目标上,无面域→顶点域插值损失;
3. **边界 Dirichlet**——开放面(平面/布料)边缘不再塌陷失真;
4. **稀疏均匀种子**——1/20 顶点随机种子在任意拓扑上都快速成图。

### 1.3 其弱点(不照搬的理由)

- **破坏性**:Remesh 与位移直接改原网格(仅靠 UNDO);
- 无实时预览(批处理 500 步)、无多系统、无 2D;
- Numba 经 pip subprocess 安装,违反 extensions.blender.org 平台规则(禁原生 wheels);
- 非归一化拉普拉斯依赖均匀网格,密度不均时图案漂移更明显。

## 2. 本项目已落地的改进(本轮)

| # | 改进 | 实现 | 验证 |
|---|---|---|---|
| 1 | 顶点域求解器 | `core/vertex_rd.py`:边图构建/边界检测/稀疏种子/顶点 RD 步进(纯 numpy,零 bpy) | 回归 11/11(含边界保持、图案成形、空网格) |
| 2 | 一键顶点凹凸操作符 | `RD_OT_apply_vertex_displacement`:顶点域 RD(边界保持开)+ V 归一化 + 沿法线直接位移,UNDO 可回退;面板 ⑥ 输出区按钮 + 强度滑块(-0.5~0.5) | 语法通过;Blender 运行时待冒烟 |
| 3 | 均匀稀疏种子选项 | seed_region 新增 `uniform_sparse`(约 5% 随机点),grid 与 mesh 双路径接线 | 语法通过 |
| 4 | 7 组风格化预设 | pro_coral/spots/maze/worms/scifi/circuit/mechanical(外部插件同款 (f,k),Karl Sims 经典区),合入预设下拉(共 12 组),**现有五组未改动** | 下拉 12 条验证通过 |

## 3. 评估结论与后续建议

- **推荐用法**:网格模式选 pro_* 预设 + seed_region=均匀稀疏 → 质量检查/三角化副本(均匀化)→ 一键顶点凹凸(直接几何)或一键 GN 凹凸(非破坏)——两条路径分别对应"快出效果"与"可调参数"。
- **后续可做**(未纳入本轮):自动 Remesh 引导(一键 voxel remesh 副本,复用其 voxel_size 公式)、三角转四边(美化拓扑,可选)、Numba/GPU 加速(受平台规则限制,走 compute shader 计划)。
