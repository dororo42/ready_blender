# Blender 运行时冒烟检查清单(C1-C6)

> 用途:在装有 Blender 4.2/4.5 的机器上执行运行时验证;本机无 Blender,以下六项为交接清单。
> 每个用例含:前置 / 步骤 / 预期 / 记录项。

## C1 · 插件注册与双版本安装

- 前置:Blender 4.2 LTS 与 4.5 LTS 各一台(或先后安装)
- 步骤:① `blender --command extension build` 打包 ② 扩展面板从磁盘安装 ③ 启用 ④ 禁用→再启用×3
- 预期:无报错;N 侧栏出现 Ready 面板;重复启用无 "already registered"
- 记录:版本号 / 控制台输出 / 面板截图

## C2 · 2D 规则网格全流程(含 O1 自动切区)

- 前置:C1 通过,默认场景
- 步骤:① 面板「域」切到规则网格(观察工作区是否自动切出 Image Editor,记下被转换的原区域类型)② 加载预设 Spots ③ 初始化 ④ 播放 10s ⑤ 暂停 ⑥ 切回网格模式(观察区域是否还原)
- 预期:域切换瞬间出现 Image Editor 且显示 RD_preview;播放时斑图演化;切回 3D 时原区域类型还原
- 记录:自动切区体验评价(O1)/ 步速实测读数 / 截图

## C3 · 3D 网格全流程(顶点色 + 预处理)

- 前置:C1 通过,场景含 Suzanne
- 步骤:① 域=网格,Suzanne 为目标 ② 质量检查(记录报告八项)③ 三角化副本 ④ 输出模式=顶点色 ⑤ 视口着色→颜色=属性/顶点色 ⑥ 初始化 ⑦ 播放 20s
- 预期:报告面板出现类别/顶点/面/边长极差/狭长/CV/密度/均匀/数量;副本生成、原对象不动;视口表面出现随浓度变化的顶点色斑图
- 记录:报告数值 / 顶点色截图 / 副本对象名

## C4 · 画笔(2D 与 3D 各一次)

- 前置:C2/C3 初始化完成
- 步骤:① 2D:Image Editor 面板点画笔 → 在图像区按住左键拖动 → ESC ② 3D:3D 视图面板点画笔 → 在物体表面按住左键拖动 → 回车 ③ 非物体模式下点画笔(应报错提示)
- 预期:2D 涂抹处出现色块;3D 涂抹处顶点色变化;状态栏提示按模式显示;点 UI 不退出画笔;ESC/右键撤销
- 记录:涂抹前后截图 / 报错文案 / 撤销行为

## C5 · 烘焙与性能预算

- 前置:C2 通过(256²)与 C3 通过(50k 面副本)
- 步骤:① 256² 烘焙 10000 步计时 ② 50k 面烘焙 10000 步计时 ③ 烘焙中点取消 ④ 再烘焙确认正常(取消标志复位)
- 预期:256² ≤5 分钟(M3 实测约 13s 量级);50k 面 ≤5 分钟(实测约 152s 量级);取消后再次烘焙正常完成
- 记录:两档实测耗时 / 取消行为 / 面板进度条

## C6 · 多系统运行(5 系统 × 2D)

- 前置:C1 通过
- 步骤:系统下拉逐个选 FitzHugh-Nagumo / Brusselator / Turing(Schnakenberg)/ Oregonator(BZ) → 初始化 → 播放 30s → 记录
- 预期:四个公式系统均能演化出对应形态(FHN 兴奋波/Brusselator 斑图/Schnakenberg 条纹/Oregonator 波纹),无 NaN 报错;参数区显示"文献默认值"
- 记录:每系统截图 + 步速 / 是否 NaN / 形态评价
