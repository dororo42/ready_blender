# Ready 插件使用说明(典型案例版)

> 版本 v0.1.1 | 本文档只讲"怎么用",不含安装/卸载(见 ready-blender-usage-guide.md)。
> 面板按操作逻辑分六步:1 模式 → 2 预处理(3D) → 3 参数→初始化 → 4 初始条件 → 5 运行 → 6 输出。

---

## 案例一:2D 规则网格 → 斑图纹理

**目标**:在 256×256 规则网格上跑 Gray-Scott,得到一张斑图纹理,并可贴到任意网格。

1. 把任意区域切为 **Image Editor**,N 侧栏 → **Ready RD (2D)** 面板(2D 模式全流程都在这里,不用回 3D 视口)
2. 点 **加载预设** → 选 "Pearson 1993 · 斑点 (Spots)" → **初始化模拟**
3. 点 **播放**(或 **烘焙** 跑满 10000 步),图像实时演化(**无需摄像机**)
4. 6 输出里切换 a/b 化学、colormap、色标范围

**不只是图片--三种用法**:
- **存图**:Image Editor 右键 RD_preview → 另存为 PNG/EXR
- **当纹理贴到网格**:选中物体 → Image Editor 面板底部点 **"把 RD_preview 接到活动物体材质"**(自动新建 `RD_texture` 材质并接 Image Texture 节点,不改你现有材质);之后 UV 展开即可在物体表面看到斑图,且播放时**实时更新**
- **手动接节点**:任何材质的 Image Texture 节点选 `RD_preview` 图像即可

**2D 画笔用法**(本模式画笔直接在 Image Editor 里画,不需要 3D 视口):
1. 初始化后点 **画笔涂抹**,鼠标移到 Image Editor 图像区域
2. **按住左键拖动**涂抹(画在网格坐标上,半径/值/化学在面板4可调)
3. **ESC / 右键** 撤销退出;**回车** 确认

**关键参数**:F=0.0367 / k=0.0649(斑点);改 F/k 换风格(见速查表)。

## 案例二:3D 网格 → 顶点色(视口直接看)

**目标**:在网格表面跑反应扩散,结果以顶点色直接显示。

1. 选一个网格物体(建议先预处理,见案例四)→ 1 模式选 **网格 (MeshRD)** → 目标网格选它
2. 3 加载预设 → 初始化
3. 6 输出模式选 **顶点色**
4. **视口右上角着色小球 → 颜色选"属性/顶点色"**(默认"材质"看不到,关键一步)
5. 5 播放,物体表面出现随浓度变化的红蓝渐变斑图

**注意**:若看不到,检查两步--输出模式=顶点色、视口着色=属性/顶点色。

---

## 案例三:3D 网格 → Geometry Nodes 置换雕刻

**目标**:把浓度当作高度,在表面做置换雕刻(珊瑚/侵蚀效果)。

1. 同案例二初始化并播放若干步(让斑图成形)
2. 6 输出模式选 **命名属性 (GN)**(默认写入 FACE 域 RD_value)
3. 给物体加 **Geometry Nodes** 修改器,新建节点树:
   - `Position` → `Named Attribute`(名称 `RD_value`,数据类型"面")→ `Math(乘)` 设强度 → `Set Position` 的 Offset,配合 `Normal` 节点
4. 斑图即变为表面凹凸雕刻;调强度/继续播放观察演化

**关键**:RD_value 是面域属性;置换在顶点域,GN 会自动插值。

## 案例四:3D 网格预处理(均匀三角 + 数量判定)

**目标**:把任意网格变成"均匀三角网 + 数量达标",避免花纹尺度漂移。

1. 选中目标物体 → 1 模式 = 网格 → 2 网格预处理 → 点 **质量检查**
2. 面板报告显示:类别(三角/四边/n-gon)、顶点/面数、边长极差、狭长占比、面积CV、面密度、均匀性✓/✗、数量✓/✗
3. 若报告提示狭长/密度不均 → 点 **三角化副本**(生成 `<原名>_rd_tri` 副本,原物体不动)
4. 若提示"数量不足" → 给副本加 Subdivision Surface 或 Voxel Remesh 提密度,再 **质量检查** 确认数量 ✓
5. 用副本作为目标网格继续模拟

**判据**:狭长占比 ≤20%、面积CV ≤0.5、边长极差 ≤10 = 均匀 ✓;面密度(面数/包围盒对角线)≥ 目标值(默认 12,可调)= 数量 ✓。

## 案例五:UV 烘焙纹理(Python API,库层)

**目标**:把网格直跑的浓度结果烘焙到 UV 纹理(贴材质/导出)。

```python
import bpy, sys
sys.path.insert(0, "<插件目录>")
from adapters.uv_bake_blender import bake_uv_texture
from controller.engine import get_engine

obj = bpy.context.scene.ready_settings.target_object
engine = get_engine()
face_values = engine.fields[1]           # b 场(面域)
img = bake_uv_texture(obj, face_values, "RD_bake", res=1024)
# 之后把 RD_bake 接到材质节点的 Image Texture
```

> 说明:UV 烘焙与 vti/vtu 导入等 M2 库层能力目前走 Python API,UI 入口列后续版本。

## 画笔使用约束(重要)

画笔是 **modal 操作符**,有明确限定:

1. **必须在对象模式(OBJECT)**:编辑模式/雕刻模式下不可用(会报错提示)
2. **必须已初始化**:先点 3 初始化模拟,再点画笔
3. **在 3D 视图内拖动涂抹**:点"画笔涂抹"后,鼠标移到 3D 视图,按住左键拖动
4. **右键** 撤销本次涂抹并退出;**ESC / 回车** 保留涂抹直接退出
5. 点击侧栏/菜单等 UI 位置会**自动退出画笔**(不会卡死)
6. 进入画笔会自动暂停模拟,涂完可继续播放

## 常用参数速查

| F | k | 图案 |
|---|---|---|
| 0.030 | 0.062 | 斑点(Spots) |
| 0.0367 | 0.0649 | 有丝分裂(Mitosis) |
| 0.0545 | 0.062 | 珊瑚生长 |
| 0.058 | 0.065 | 蠕虫 |
| 0.026 | 0.051 | 混沌纹理 |

扩散系数保持 Du=0.16 / Dv=0.08,只在 F∈[0.02,0.08]、k∈[0.045,0.07] 内探索。
