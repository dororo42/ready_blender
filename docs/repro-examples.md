# 可操作复现示例(Reproduction Cases)

> 文档版本:v1.0 ｜ 适用插件:v0.1.1 ｜ 目标:让测试人员无需原作者口述即可按步骤独立复现每个功能点。
> 每个案例包含:前置条件 / 操作步骤 / 预期结果 / 截图占位 / 通过判据。

---

## C1 · 预设加载(Pearson 1993 五组,规则网格模式)

- **前置条件**:Blender 4.2/4.5 已安装插件(Ready v0.1.1);默认场景即可。
- **操作步骤**:
  1. 3D 视口按 N 打开侧栏 → Ready 面板
  2. **域(Domain)** 保持 `规则网格 (2D)`,网格尺寸 256,勾选 Wrap
  3. 点 **加载预设(Pearson 1993 五组)**
  4. 在弹出的搜索菜单中依次查看五组名称
  5. 任选 "Pearson 1993 · 斑点 (Spots)" → 回车
- **预期结果**:
  - 下拉菜单显示五组中文名称**无乱码**:斑点 / 珊瑚生长 / 有丝分裂 / 蠕虫 / 混沌纹理
  - 选中后参数区自动变为 F=0.0367、k=0.0649、Du=0.16、Dv=0.08、dt=1.0
  - 状态提示 "Ready: 已加载预设 Pearson 1993 · 斑点 (Spots)"
- **截图占位**:`docs/screenshots/C1_preset_dropdown.png`(下拉展开态)+ `C1_after_load.png`(参数区)
- **通过判据**:下拉无乱码;五组参数与下表一致。

| 预设 | F | k |
|---|---|---|
| 斑点 | 0.030 | 0.062 |
| 珊瑚生长 | 0.0545 | 0.062 |
| 有丝分裂 | 0.0367 | 0.0649 |
| 蠕虫 | 0.058 | 0.065 |
| 混沌纹理 | 0.026 | 0.051 |

## C2 · Image Editor 出图(2D 三步入图,无摄像机)

- **前置条件**:同 C1,完成预设加载。
- **操作步骤**:
  1. 点 **初始化模拟**
  2. 点 **步进**(或播放几秒)
  3. 把任意编辑器区域切换为 **Image Editor**(Shift+F10 或区域类型菜单)
  4. 若侧栏可见,在 Image Editor 按 N 查看 Ready 面板
- **预期结果**:
  - Image Editor 显示 `RD_preview` 图像,内容为灰色/彩色斑图(**不需要任何摄像机**)
  - 图像随播放/步进更新
  - 若视口仍空白,点 Image Editor 侧栏 Ready 面板的 **刷新显示** 按钮
- **截图占位**:`docs/screenshots/C2_image_editor_pattern.png`
- **通过判据**:全程无摄像机,Image Editor 可见斑图且随模拟更新。

## C3 · 摄像机与对象选择规则验证

- **前置条件**:新场景,含 Suzanne(默认猴头)和一个球体。
- **操作步骤**:
  1. Ready 面板 **域** 切到 `网格 (MeshRD)`
  2. **不选任何对象**,点 **初始化模拟** → 观察
  3. 面板 ① 区块 Target Mesh 选球体 → 再初始化 → 观察
  4. 删掉场景所有摄像机,重复 C2 流程 → 观察
- **预期结果**:
  - 步骤 2:使用**当前活动对象**(默认 Suzanne)成功初始化;面板显示提示"未选目标时默认使用当前活动物体"
  - 步骤 3:模拟目标切换到球体
  - 步骤 4:规则网格模式出图**不受摄像机影响**;网格模式也不依赖摄像机(依赖的是 3D 视口与着色显示)
- **截图占位**:`docs/screenshots/C3_default_active_object.png`
- **通过判据**:未选对象时按活动对象初始化且有 UI 提示;无摄像机时规则网格出图正常。

## C4 · 均匀网格预处理(质量检查 + 三角化副本,非破坏)

- **前置条件**:场景含 Suzanne(默认 4 边面网格,含密度不均区域)。
- **操作步骤**:
  1. Ready 面板 → 域 = 网格 → Target Mesh 选 Suzanne
  2. 点 **质量检查**(⑥ 区块)
  3. 记录面板报告(顶点/面数/边长极差/狭长占比/面积CV/面密度/均匀性/数量)
  4. 点 **三角化副本**
  5. 确认场景多出一个 `Suzanne_rd_tri` 对象,**原 Suzanne 仍在且未改动**
  6. 把 Target Mesh 改为副本,再次 **质量检查**,对比指标
- **预期结果**:
  - 步骤 3 首次报告:Suzanne 为四边面(三角化后分析),可能提示面积 CV 或狭长占比超标
  - 步骤 4 副本为全三角面;原对象完好(非破坏)
  - 步骤 6 副本报告显示 n_faces 增加、全部为三角面
- **截图占位**:`docs/screenshots/C4_before_report.png` / `C4_after_copy.png`
- **通过判据**:报告指标可读;副本生成且原对象未动;两次报告数值不同且有记录。

## C5 · 数量不足处理(低模 → 提示 → 细分后达标)

- **前置条件**:场景含一个低模物体(如默认 Cube 不细分,12 个三角面)。
- **操作步骤**:
  1. Target Mesh 选 Cube → **质量检查**
  2. 观察报告:面密度与"数量 ✓/✗"标记
  3. 给 Cube 加 Subdivision Surface 修改器(2 级)→ 应用
  4. 再次 **质量检查** → 对比
- **预期结果**:
  - 步骤 2:报告提示"网格数量可能不足:面密度 x.x(目标 ≥ 12)"且数量 ✗
  - 步骤 4:面数大幅增加,数量 ✓;若仍有狭长/密度问题,报告会继续列出
- **截图占位**:`docs/screenshots/C5_low_poly_warning.png` / `C5_after_subdiv.png`
- **通过判据**:低模被判定数量不足并提示;细分后重新检查通过或提示减少。
